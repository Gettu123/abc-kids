# Abejita

Juego educativo para niños de 4 a 5 años. Español de Venezuela y portugués.

## Qué incluye

- Perfiles locales (varios niños en el mismo aparato)
- Memoria, conteo 1–10, letras del nombre, figuras y animales
- Voz (Web Speech API) y sonidos
- Control parental con suma y límite de pantalla
- Progreso y medallas en `localStorage`

## Cómo jugar

1. Elige idioma (ES-VE o PT)
2. Crea el perfil con nombre y si es niño o niña
3. Entra a cualquiera de las 5 áreas del menú
4. Ajustes parentales: icono de engranaje (pregunta de suma)

El progreso queda guardado en el navegador.
